# 零件公差逆向数据集生成逻辑说明书

本说明书描述从**设计规格（图纸）**出发，生成包含制造误差的三维实体，模拟真实物理扫描（含飞点与噪点），并最终经过滤波输出为纯算法输入的完整流水线逻辑。

---

## 1. 总体数据流转逻辑

整个流水线分为四个级联阶段，真值（Ground Truth）在流转过程中被严格记录：

1. **设计层 (Design Level)**：定义图纸理论规格。对应 `spec.json`（共 396 个设计）。
2. **实例层 (Instance Level)**：生成具有物理尺寸偏差的零件实体。对应 `STEP` 文件与 `instance_metadata.csv`。
3. **点云层 (Point Cloud Level)**：模拟扫描仪采集，注入物理缺陷。对应 `_dirty.ply` 文件。
4. **算法输入层 (Algorithm Input Level)**：滤除扫描缺陷，输出纯坐标文件。对应 `_filtered.xyz` 文件。

> **数据集规模**：包含长方体、圆柱、球、阶梯轴、带孔板 5 个零件族，共 396 个设计，每个设计生成 100 个实例，总计 **39,600 个样本**。

---

## 2. 阶段一：实例层生成逻辑 (制造误差模拟)

### 2.1 目标
将设计层抽象的“公差带”转化为每一个实体零件具体的“实际物理尺寸”。

### 2.2 核心算法：截断正态分布抽样
真实的机加工过程产生的尺寸偏差通常服从正态分布，且因质检剔除，超出公差带的极值被截断。

对设计层给定的每个维度：
- 下限：$LSL$
- 上限：$USL$
- 公差带宽度：$T = USL - LSL$
- 公差中心：$\mu = \frac{USL + LSL}{2}$

设定目标过程能力指数 $C_p$（默认取 1.33，代表工艺稳定），计算分布标准差：
$$
\sigma = \frac{T}{6 C_p}
$$

使用**拒绝采样法**生成实际尺寸 $X$：
1. 从正态分布 $N(\mu, \sigma^2)$ 中抽取随机数 \(x\)。
2. 若 \(LSL \le x \le USL\)，则接受该值作为该维度的实际尺寸；否则重新抽取。

### 2.3 几何实体构建 (STEP 导出)
将抽样得到的实际尺寸注入三维建模引擎（CadQuery / OpenCASCADE 内核）。针对 5 种零件族构建：
- **长方体 (Box)**：`Box(L, W, H)`
- **圆柱 (Cylinder)**：`Circle(D / 2).extrude(H)`
- **球体 (Sphere)**：`Sphere(D / 2)`
- **阶梯轴 (Stepped Shaft)**：基于大径 `D1` 和高 `H1` 挤出，再在顶面基于小径 `D2` 和高 `H2` 挤出。
- **带孔板 (Hole Plate)**：基于长宽高 `L, W, H` 挤出长方体，随后在顶面几何中心打贯穿孔 `D`。

导出为 `.step` 格式。该格式基于 B-Rep（边界表示法），为无损几何，浮点数精度达 1e-7 mm，不会丢失任何微米级公差。

### 2.4 实例层真值记录
为每个实体生成一行 CSV 记录 `instance_metadata.csv`，包含：
- `instance_id`：实例编号。
- `actual_{dim}`：该实例每个维度的绝对真实物理尺寸（保留 6 位小数）。

## 3. 阶段二：点云层生成逻辑 (扫描物理仿真)

### 3.1 目标
模拟激光/结构光扫描仪的物理采集过程，为逆向算法提供“脏”的原始数据。

### 3.2 核心算法：网格化与表面均匀采样
1. **网格化 (Tessellation)**：将 B-Rep 实体离散化为三角面片。设定弦高误差容差（0.005 mm），确保曲面的离散化逼近真实尺寸。
2. **面积均匀采样**：使用蒙特卡洛方法在三角面片表面随机撒点（每个零件 30,000 个点）。确保复杂特征（如边缘）与平坦区域的点密度一致。

### 3.3 仪器噪声模拟
在采样点的空间坐标上叠加高斯白噪声，模拟传感器测距误差：
$$
P_{noisy} = P_{true} + \mathcal{N}(0, \sigma_{scan}^2)
$$
设传感器测距标准差 $\sigma_{scan} = 0.005$ mm。

### 3.4 物理缺陷模拟 (脏数据注入)
为了测试逆向算法对非理想输入的鲁棒性，注入两类典型缺陷：
1. **边缘飞点 (Flying Pixels)**：
   - 逻辑：提取 2% 的表面点，查询其所在面片的法线方向。
   - 操作：将这些点沿法线向外平移随机距离（0.1 至 2.0 mm），模拟激光光斑打在零件边缘时同时反射到背景导致的“拖尾”现象。
2. **空间悬浮噪点 (Dust / Random Noise)**：
   - 逻辑：在零件包围盒（Bounding Box）向外扩展 2.0 mm 的空间内，随机生成 300 个悬空点。模拟镜头灰尘、环境光散射等引起的杂点。

### 3.5 数据输出 (PLY 导出)
将混合了表面点、飞点、噪点的集合随机打乱顺序后，导出为 `.ply` 格式。
采用 **Binary Encoding（二进制编码）**，在保持高密度点云的同时，大幅压缩文件体积。

---

## 4. 阶段三：滤波与格式转换 (算法输入准备)

### 4.1 目标
清洗点云数据，去除噪点与飞点，并转换为算法易读的纯坐标文本格式（XYZ）。

### 4.2 统计离群点移除 (SOR)
使用 **Open3D** 的统计滤波算法：
1. 计算每个点到其最近的 \(k\) 个邻居（默认 \(k=30\)）的平均距离。
2. 假设这些平均距离服从正态分布，剔除平均距离超过全局均值加上 \(1.5\) 倍标准差（`std_ratio=1.5`）的离群点。
3. 此步骤能精准剔除空间悬浮噪点以及边缘飞点，同时最大程度保留零件表面的真实形貌特征。

### 4.3 XYZ 输出
将滤波后的点云坐标直接导出为无头文件的 `.xyz` 纯文本格式（保留 6 位小数）。
格式示例：
```text
19.995378 39.998211 10.002134
19.982115 40.012411 9.991534
